# Sources

Manifest of everything in `../raw/`, maintained by `compile-wiki`. One row per file, with its full path relative to `raw/` in the Source column (no lists, globs or bare names). A source with no row here (or whose file changed after its "Last compiled" value) is pending. "Last compiled" is the local date and time it was compiled, `YYYY-MM-DDTHH:MM` (e.g. `2026-11-12T09:40`), so an edit later the same day shows up; older rows with only a date are compared by day.
